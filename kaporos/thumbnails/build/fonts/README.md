# fonts

Drop your licensed brand fonts here and name them by role. The build looks for these files first and falls back to the bundled open fonts if they are missing:

| Role | File to add | Fallback bundled |
|---|---|---|
| condensed (headline caps) | `condensed.ttf` or `condensed.otf` | Anton (OFL) |
| serif-italic (accent word) | `serif-italic.ttf` or `.otf` | Playfair Display Black Italic (OFL) |

Licensed fonts are fine to keep in a private repo. Do not commit them to a public one.
