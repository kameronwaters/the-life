# house — the actual Christspiracy thumbnail style

Built to match the channel's own thumbnails (Thug Rose, Meat Isn't Masculine): heavy condensed caps, white with one word in the brand red, hard black drop shadow, optional serif italic accent word, dark cinematic image, nothing else on the frame. No eyebrow, no strapline, no bars.

- `house_v2_serif.jpg` — HE'S THE in condensed, Messiah!? in serif italic bottom-left, the Thug Rose layout.

Red sampled from your own thumbnails: #E45428. Type here is Anton (Google Fonts) as a stand-in for the condensed face in your library, which I could not pull: the Drive folder is unreadable from this session (connector lacks file-read scope). Drop the real font in and re-set; the layout files are 1280x720 and the text positions are in the build script in `../../thumbnails/house/README.md` notes below.

Positions (1280x720): line 1 at x40 y22, size 168; line 2 at x40 y190, size 168; shadow offset 6,8 blur 10; 3px dark stroke. Image shifted down 110px with a black-to-clear gradient over the top 330px.
