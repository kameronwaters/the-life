# house — the actual Christspiracy thumbnail style

Built to match the channel's own thumbnails (Thug Rose, Meat Isn't Masculine): heavy condensed caps, white with one word in the brand red, hard black drop shadow, optional serif italic accent word, dark cinematic image, nothing else on the frame. No eyebrow, no strapline, no bars.

- `house_v2_serif.jpg` — HE'S THE in condensed, Messiah!? in serif italic bottom-left, the Thug Rose layout.
