# scriptural-proofs

Receipts for arguments I make from scripture. Every claim gets checked against the
primary source (the verse, the Church Father, the manuscript) before it gets filed.
Nothing goes in here on the strength of a sermon or a YouTube video alone.

## how a note is graded

Each claim in a fact-check carries one of:

- **CONFIRMED** — primary source checked, wording and reference match
- **CONFIRMED, overstated** — the fact is real but the talk stretched it
- **NOT CONFIRMED** — could not find support, or the evidence cuts the other way
- **FALSE** — primary source contradicts the claim

## folders

- [fish/](./fish) — every "fishy" Bible story that gets used against a plant-based reading of Jesus: John 21, Luke 5, Luke 24, the loaves and fishes, the net parable, the coin in the fish, Jonah.

## conventions

- `README.md` in each folder is the index of stories plus the one-line verdict for each
- one `.md` per argument or talk being checked, named by topic
- `sources/` holds raw material (transcripts, scans) so the fact-check can quote it
- cite the exact chapter/section of a Father (e.g. `Against Praxeas 25`), not just the author
